# FACTORIAL 4 (`4! = 24`)

Portal web de juegos casuales multijugador para **hasta 24 jugadores por partida**, con identificación persistente sin cuentas y récords guardados en el servidor.

## Juegos incluidos (24 jugadores)

- **Campal** — Batalla campal pixel art 3/4 en una sola arena.
- **Cube Racer 3D** — Carreras 3D con parrilla 4×6 y pistas procedurales.
- **CXVallas 24** — Carrera de vallas pixel art en estadio de 24 calles.
- **MecanoRace** — Gran premio de mecanografía en tiempo real con fantasma del récord.
- **Racer Master** — Carreras arcade pseudo-3D estilo OutRun a 2 vueltas.
- **Tròbix** — Batalla sincronizada sobre 10 mapas interactivos SVG (ES/CA).

## Requisitos

- **Node.js 18+** (sin dependencias externas, no requiere `npm install`).

## Clonar y poner en marcha

```bash
git clone https://github.com/gerardfp/factorial4.git
cd factorial4
npm start
```

Abre `http://localhost:3000` en tu navegador (puedes cambiar el puerto con `PORT=8080 npm start`).

## Pruebas
